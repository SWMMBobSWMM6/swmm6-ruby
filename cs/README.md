# SWMM6 1D engine in C#

A translation of the OpenSWMM 1D engine (HydroCouple/openswmm.engine, branch `swmm6_rel`, commit 88329d6) from
C++ to C#, held to byte-identical output: the same `.out` file and the same `.rpt` report (apart from the three
clock lines) as the C++ engine built from the same commit and run on one thread.

- `gen/` - generated by `tools/cpp2x/emit_cs.py` from clang's AST of every engine source file. Not edited by hand.
- `runtime/` - the parts of the C++ standard library the generated code calls (strings, vectors, maps, streams,
  printf, filesystem), the command-line program (`Program.cs`, from `src/cli/main.cpp`), and a few hand-written
  replacements for code that touches the operating system (`Hand_*.cs`, each with its reason at the top).
- `build.sh` - compiles both with the .NET SDK's C# compiler into `bin/openswmm.dll`.

Run a model the way the C++ command line runs it:

    dotnet bin/openswmm.dll model.inp model.rpt model.out

The reference engine uses OpenMP in nine files. The port runs every parallel loop on one thread, in order,
which is what the reference does when it is held to one thread (`OMP_NUM_THREADS=1 OMP_THREAD_LIMIT=1`). See
`../AI-USE.md` for how AI was used.
